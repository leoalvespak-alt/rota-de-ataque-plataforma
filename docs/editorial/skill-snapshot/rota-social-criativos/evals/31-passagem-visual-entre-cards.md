# 31: continuidade de imagem em dois cards

**Pedido:** Em um carrossel de oito cards, crie uma passagem visual entre dois cards consecutivos usando um recorte sem fundo que avance para o card seguinte.

**Golden case:** O recorte mantém escala, posição e luz entre as duas peças. Cada card tem copy completa e legível sozinho. A emenda não atravessa palavras, dados ou parte essencial de uma captura.

**PASS:** A imagem parece continuar quando os cards são vistos lado a lado, e cada PNG funciona isolado. O recorte tem transparência real, sem halo indesejado.

**FAIL:** Há salto de escala/posição na emenda; a pessoa ou objeto parece duplicado; texto depende do card vizinho; uma captura, palavra ou CTA é cortado para criar continuidade.
