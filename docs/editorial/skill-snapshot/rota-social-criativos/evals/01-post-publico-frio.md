# 01 — Post para público frio

**Pedido:** Crie um post estático para alguém que considera estudar para PPPE ou PPPB, mas ainda não conhece a Rota.

**Contexto:** Há plano real e uma missão verificável. Avalie o PNG em escala de celular.

**PASS:** Concurso e situação do aluno identificados; tensão/benefício em linguagem comum; CTA claro sem depender da legenda. Alegações sobre o plano são verificadas; screenshot só entra se melhorar a peça e, quando entra, é legível.

**FAIL:** “Missão 324” sem contexto, interface minúscula, lista técnica de recursos ou slogan vazio sem significado para o aluno.
