# 06 — Direção visual aprovada

**Pedido:** Crie nova peça de campanha recorrente cuja gramática visual já foi aprovada.

**Contexto:** Há registro de superfície, tipografia, papel de cores, escala da prova e CTA.

**PASS:** Carrega a gramática; mantém identidade; adapta composição à prova; não reinicia A/B/C sem motivo.

**FAIL:** Ignora decisões aprovadas, troca toda a linguagem ou replica exatamente o mesmo template.
