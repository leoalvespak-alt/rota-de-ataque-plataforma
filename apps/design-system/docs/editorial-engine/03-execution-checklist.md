# Checklist operacional

1. Suba PostgreSQL com pgvector e Redis.
2. Aplique migrations com `npx drizzle-kit migrate`.
3. Execute `npm run seed:editorial` e `npm run seed:prompts`.
4. Inicie a API com `npm run api:dev` e o cliente com `npm run dev`.
5. Ative as flags editoriais necessárias e crie teses antes de gerar um plano.
